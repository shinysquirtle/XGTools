# XGTools 工作工具箱
可扩展的 Windows x64 JavaFX 桌面工具箱，首个模块为 PDF 压缩。文件全部在本机处理，无服务器、数据库和 HTTP 接口。


## 版本
当前版本从 1.0 开始。版本号统一维护在 pom.xml 的 project.version 中；Maven 构建会生成版本资源，左下角显示“版本 1.0”，运行和打包脚本自动读取同一版本号。
修改版本后先运行 mvn package，再运行或打包。仓库包含开发所需的内置 Ghostscript；target、dist 和 IDEA 本地配置不提交。
## 功能
拖拽/批量添加 PDF、清晰/均衡/体积优先、后台串行压缩、取消、失败重试、大小对比、输出目录和配置记忆。
默认保留原件，输出重名自动加序号；压缩变大则不保存新文件。单文件超时 30 分钟。
进度条表示批次文件完成比例，不表示当前文件内部进度。
PDF 会被重写，图像、交互表单、注释、签名等可能受影响；重要文件需核对输出。

## 开发
JDK 21、Maven 3.6.3+、Windows x64、Ghostscript。
在 IDEA 中作为独立 Maven 项目打开本目录，项目 SDK 选择 21。
执行 `mvn clean package` 后执行 `mvn javafx:run`，或运行 Launcher.main。
PowerShell：`./scripts/run.ps1 -JavaHome '你的JDK21目录'`。
开发运行使用项目 vendor/ghostscript，打包运行使用应用目录 ghostscript；界面不提供引擎选择，也不会回退到本机其他安装。

## 打包
先执行 `mvn clean package`。
- 免安装应用目录：`./scripts/package.ps1 -JavaHome '你的JDK21目录'`
- 打包脚本固定包含 vendor/ghostscript，无需额外参数；当前只生成本机测试应用目录。
- EXE/MSI 安装包：追加 `-Type exe` 或 `-Type msi`，需安装当前 JDK 要求的 WiX。
输出在 dist 下带时间戳的目录。分发整个 XGTools 文件夹，不能只复制其中的 EXE。
生成的应用目录包含 Java 运行环境和 Ghostscript，使用者无需另行安装或配置。不要只复制 EXE，测试时保留整个应用目录。
配置保存到 %LOCALAPPDATA%/XGTools/settings.json；不把本机绝对路径写入发布配置。

## 验证
`mvn test` 执行输入校验及真实 Ghostscript 集成测试。
集成测试通过环境变量 GHOSTSCRIPT_EXE 指定程序；本机 D:/Tools/ghostscript 为备用路径。
缺少引擎时集成测试显式跳过。测试覆盖中文空格路径、收益判断、重名保护、取消和损坏文件。
发布前在无 Java 的干净 Windows 环境检查启动，并人工核对扫描件、文本、表单、签名文件的输出。
本项目没有 HTTP 接口或 Mapper，因此不引入 Swagger、MyBatis。

## 目录
- XGToolsApp / Launcher：应用外壳与入口
- core：工具扩展接口和注册表
- common：统一异常、结果
- tools/pdf：PDF 工具界面、模型及服务
- scripts：运行和 Windows 打包脚本

当前包含 PDF 压缩与图片压缩/水印两个工具模块。没有后台服务器需要启动。

## 图片压缩与水印
在左侧选择「图片压缩」。支持 JPG、JPEG、PNG、BMP，可批量添加或拖入。
- 压缩：沿用参考项目的 Hutool 编码，默认质量 20%，可调整至 1%～100%，统一输出 JPG；透明像素填白色，不改变尺寸。
- 水印：内置从 questionmanage-java-01 原样复制的 watermark/guoshi.png；也可选择自定义图片或恢复默认。
- 水印参数与参考实现一致：宽度 340px、角度 −45°、透明度 1.0，水平间隔 60px、垂直间隔 180px，奇偶行交错平铺。
- 同时勾选时先加水印再压缩；仅加水印时 PNG 输出仍为 PNG，其他格式输出 JPG。
- 原件始终保留，重名自动添加序号；压缩结果即使变大仍输出 JPG，并在列表提示。
- 支持取消；当前图片编解码不能瞬间中断，完成后会丢弃未发布的临时结果。再次开始会按当前设置重新处理整个列表。
- 单图上限 4000 万像素；暂不支持 GIF 动画、WebP、HEIC。与参考实现一致，按像素处理，不保留 EXIF 等元数据。
- 设置单独保存到 %LOCALAPPDATA%/XGTools/image-settings.json，不影响 PDF 工具。
- 不访问 OSS 或其他网络服务；默认水印随 JAR 和 Windows 应用目录分发。
## PDF 高级压缩
根据用户提供的《PDF压缩经验总结（给Agent参考）》新增以下模式：

| 模式 | 用途 |
|---|---|
| 常规压缩 | 保留原有 /printer、/ebook、/screen 预设 |
| 增强降采样 | 默认 110 DPI，关闭 JPEG 直接透传，强制彩色/灰度图片降采样与 DCT 重编码；保留可搜索文字 |
| 整页栅格化 | Ghostscript 以 200 DPI / JPEG 85 / CropBox 渲染一次，再缩到指定 80～200 DPI，按指定 JPEG 质量封装 |
| 自动压到目标大小 | 默认 20 MB；已经达标的原件跳过；内容流估算不超过目标 60% 时先尝试降采样，否则走栅格化；按 150、140、130、120、110、100、90、80 DPI 顺序尝试 |

1 MB 按 1024×1024 字节计算。自动模式逐档检查最终 PDF 的真实大小，栅格化优先留 5% 余量。
最低 80 DPI 仍不达标时，保留最小且有效的结果，状态显示“未达目标”，文件名带“未达标”；若没有体积收益则保留原文件。
可以降低 JPEG 质量或提高目标大小后再次处理。自动模式不会承诺所有 PDF 都能压到设定体积。
JPEG 质量仅作用于栅格化，不会将 -dJPEGQ 错用到 pdfwrite。

### 诊断与核验
“诊断选中 / 全部”展示总大小、页数、图片流大小、内容/Form 流估算和 CropBox 裁切页数。
统计为压缩流长度估算，包含 Form，不能精确区分所有内容类型，也不是输出大小的理论下限。
经验文档的 12/15 MB 阈值仅作参考，不当作普遍定律。
输出验证 PDF 头、EOF、所有页内容流、页数和每页物理显示尺寸，并对首/中/末页做实际渲染。
“打开选中结果”便于人工检查小字、图例和裁切页；程序校验不能代替清晰度目视检查。

### 页面与临时文件
每个文件使用随机独立工作目录，按明确页码顺序封装；每页应用自身 CropBox、旋转和 UserUnit，避免混页、空白边和强制拉伸。
应用内使用 Java2D 高质量双三次缩放、优化 Huffman 的渐进式 JPEG、PDFBox 直接封装 JPEG，不依赖 Python/Pillow/img2pdf。
这与参考脚本的 Lanczos 实现不完全相同，不保证相同大小；页面物理尺寸直接来自源 PDF，比依赖 JPEG DPI 元数据更准确。
一个文件只渲染一次，不同 DPI 从同一批 200 DPI 图片重编码。临时文件在成功、取消、失败后清理，不影响原文件。
源文件单页 200 DPI 渲染不得超过 6000 万像素。仍需足够临时磁盘空间存放渲染图和候选 PDF。
整体任务默认 30 分钟超时；取消会终止 Ghostscript，Java 编解码在当前操作结束后响应。

### 栅格化影响
整页栅格化会丢失可搜索/复制的文字、交互表单、链接等结构，不包含 OCR；签名不能保留。
只适用于接受这些变化的文档，原件始终保留。文字需可搜索时选择常规或增强降采样模式。


## 默认输出目录
PDF 和图片工具均默认输出到当前用户的 Windows 桌面，支持桌面重定向和 OneDrive。手动选择的输出目录仍会保存并优先恢复。


## 设置悬浮说明
PDF 与图片工具的全部设置、下拉选项均提供用途及结果影响说明。悬停控件或标签旁的 ? 约 0.35 秒显示，提示支持自动换行，最长显示 45 秒。灰色设置可通过其标签查看适用条件。说明包含画质/体积取舍、格式及透明度变化、文字搜索影响、自动目标的实际边界。


## 复制处理详情
PDF 和图片结果表格支持选中后点击“复制详情”、右键复制或 Ctrl+C；支持多选。双击行、按 Enter 或点击“查看详情”可打开只读详情窗口，文字可自由选择，提供“复制全部”。复制包含文件路径、执行时参数、状态、大小和完整详情；表格只展示单行摘要，不截断复制内容。滚动条与蓝灰主题统一。
